# My Current Software Development Portfolio

## run locally

```
$ npm ci
$ npm run playwright:install
$ npm start
```

The local dev server binds to `http://127.0.0.1:5173`.

This project expects Node `24.11.0` and npm `11.6.1`, matching `.nvmrc` and `package.json`.

## basic security and a11y testing

- for Playwright and a11y tests, `npm run test:headless`
- for TypeScript only, `npm run typecheck`
- for security tests, `npm run test:security` (this currently only works on linux)
